# charm-layout  > [Read in English](README.md)  Um motor de layout inspirado no Flexbox para interfaces de terminal, construído sobre o [lipgloss](https://charm.land/lipgloss/v2). Crie layouts flex e grid responsivos com dimensionamento proporcional, direção de fluxo e espaçamento — assim como o CSS Flexbox, mas para o terminal.  ## Funcionalidades  - **Layout Flex** — Direção em linha ou coluna com dimensionamento proporcional dos filhos (razões como 0.3 / 0.7) - **Layout Grid** — Distribui filhos automaticamente em colunas de largura igual - **Espaçamento (Gap)** — Espaçamento configurável entre filhos - **Geometria exata** — O container é preenchido até a largura/altura declarada, sem perder nenhuma coluna no arredondamento - **Responsivo** — `SetSize(w, h)` adapta o layout para qualquer dimensão de terminal - **Validado** — Configuração inválida é reportada (`Validate` / `RenderE`) em vez de quebrar o layout silenciosamente - **Construído sobre lipgloss** — Usa `JoinHorizontal` / `JoinVertical` internamente para renderização confiável  ## Instalação  ```bash go get github.com/junhinhow/charm-layout ```  ## Início Rápido  ### Layout Flex  ```go package main  import (     "fmt"     "github.com/junhinhow/charm-layout" )  func main() {     flex := layout.NewFlex(layout.Row).         SetSize(80, 24).         SetGap(1).         AddChild(0.3, "Barra Lateral").         AddChild(0.7, "Conteúdo Principal")      fmt.Println(flex.Render()) } ```  ### Layout em Coluna  ```go flex := layout.NewFlex(layout.Column).     SetSize(80, 24).     AddChild(0.2, "Cabeçalho").     AddChild(0.6, "Corpo").     AddChild(0.2, "Rodapé")  fmt.Println(flex.Render()) ```  ### Layout Grid  ```go grid := layout.NewGrid(3).     SetSize(90, 30).     SetGap(1).     AddChildren("Célula 1", "Célula 2", "Célula 3", "Célula 4", "Célula 5")  fmt.Println(grid.Render()) ```  ## Semântica do dimensionamento  As razões seguem a regra de `flex-grow` do CSS: o **espaço livre** do container (a largura — ou a altura, no caso de uma coluna — menos os espaçamentos) é distribuído proporcionalmente às razões.  - As razões **não precisam somar 1**. Dois filhos com razão `0.3` dividem o   espaço livre em 50/50. - A distribuição usa o método do *maior resto*, de modo que os filhos preenchem   o container **exatamente**: nenhuma coluna é perdida no arredondamento e   sobra nenhum espaço. - Uma razão `0` dá largura zero ao filho; ele continua sendo renderizado (e   truncado para zero colunas) para que o alinhamento seja preservado. - Se todas as razões forem zero, o espaço é dividido igualmente entre os filhos. - Cada filho (ou linha da grade) ocupa no mínimo uma linha de terminal.  ```go // 80 colunas, gap 1, dois filhos com razão 0.3 cada: // o primeiro filho ocupa as colunas 0..39 e o segundo 40..79. flex := layout.NewFlex(layout.Row).SetSize(80, 24).SetGap(1).     AddChild(0.3, "A").AddChild(0.3, "B") ```  ### Geometria da grade  As colunas dividem igualmente a largura disponível e o resto da divisão vai para as primeiras colunas, de modo que a linha termine exatamente na largura declarada:  ```go // 80 colunas, 10 colunas, gap 1: as colunas têm 7 ou 8 células de largura // e a linha termina exatamente na coluna 80. grid := layout.NewGrid(10).SetSize(80, 24).SetGap(1).     AddChildren("A", "B", "C", "D", "E", "F", "G", "H", "I", "J") ```  Quando o gap não cabe no espaço disponível, ele é reduzido para o maior valor que ainda cabe, de modo que o layout nunca ultrapasse o terminal.  ## Validação  `Render()` é **tolerante**: nunca entra em panic e sempre devolve uma geometria válida, ajustando valores inválidos (tamanhos negativos, gaps negativos, direções desconhecidas, razões inválidas).  `RenderE()` é **estrito**: devolve o erro de configuração e não renderiza nada. Use-o quando o layout for montado a partir de entrada do usuário.  ```go flex := layout.NewFlex(layout.Row).SetSize(80, 24).AddChild(-0.5, "A")  if _, err := flex.RenderE(); err != nil {     // err satisfaz errors.Is(err, layout.ErrInvalidRatio) }  err := flex.Validate() // mesma verificação, sem renderizar ```  Os seguintes erros sentinel são devolvidos (sempre com contexto, de modo que `errors.Is` funciona):  | Erro | Significado | |------|-------------| | `ErrInvalidDirection` | Direção de flex desconhecida | | `ErrInvalidGap` | Espaçamento negativo | | `ErrInvalidSize` | Largura ou altura negativa | | `ErrInvalidRatio` | Razão negativa, `NaN` ou infinita | | `ErrZeroRatioSum` | Todas as razões somam zero | | `ErrInvalidColumns` | Grade com menos de uma coluna |  ## Referência
